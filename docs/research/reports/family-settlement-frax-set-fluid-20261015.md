# Frax、旧版 Set、Fluid 本批正确性

Frax 复用 ERC4626 Family，补齐同步 Custodian 指定收款路径的实收及旧库存保护。当前执行器下默认与指定收款路径共32次成功、80次故障拒绝及6次零额／尘额拒绝；独立复核绑定同块状态、当前源码与执行器。历史拒绝不冒充独立存储回滚，另有真实 BotVM 合成安全测试。

旧版 Set Core 的 SetToken／RebalancingSetToken V3 四个方向完成44次实际成功及176次故障拒绝，包括88次成功调用后整体回滚；额外覆盖实际0.5%发行费。默认路径保留，Basic 指定收款与多资产路径不由这些结果升级。

Fluid 认证复用三个池、六个方向的48次成功和44次严格声明拒绝，补全4次独立历史 fork 欠资拒绝及存储回滚。原 strict 资源不足结果保留，未伪装为 strict 成功。旧执行器 artifact、源码及当前兼容性分别核验。

金额报价与请求不扣减，runtime 构造无链外 Exact 或 quoted fallback。原失败及旧 hash 保留；自然估值、原交易机会复现和4A／4B性能尚未由本批完成。未启动live、部署、签名或广播。
