# Address Profile Review Snapshots

These reports are tracked snapshots generated by `analysis/src/cli/address.ts` for external review.

The live/generated output directory remains ignored:

```text
analysis/outputs/
```

Regenerate locally with:

```bash
cd analysis
READONLY_RPC_URL=... npm run address -- --seed 0x... --chain mainnet --limit 80 --trace-top 5 --output outputs/address/0x....md
```
