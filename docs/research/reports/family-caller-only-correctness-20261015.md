# Migration 与 BTBBear 当前双执行正确性

复用既有生产实现，新增 Family 自有同状态验收入口。Migration 在 N26029585 的 ACX→USDC 路径完成8次成功、16次故障拒绝和1次零输入拒绝；BTBBear 在 N26029369 的 mint/redeem 双方向完成16次成功、32次故障拒绝和2次零输入拒绝。原交易数量及十分之一只用作输入，不改生产价格表，不借原交易输出。

当前部署代码与已验证实现、Ready准入身份和当前生产 issuer 已逐项绑定。独立复核核对144条代币余额变化、24条原生币变化、48条总供应变化及24组协议事件；完整输入扣款、报价与实际到账一致，16条适用临时授权路径均清零。两协议所选入口仅向调用者出款，不支持任意收款方或延迟付款结算回调；不要求补造不存在的协议能力。BTBBear普通转账税不被错误套在mint/burn上。

生产runtime构造链外Exact为0，无quoted fallback。当前生产build与相关合同测试有效，验收入口经独立审查。历史拒绝的空effects不冒充独立storageDiff回滚；旧机会成果保留原版本、配置及fallback模式，本次不升级自然估值、原TX机会、正式Adapter Replay或4A/4B性能。xWin的历史身份补证另行处理。
